# Mira iPhone 168 source

`Mira-ios-source-168.zip` is the full source snapshot in folder `Mira-ios`, including the retained lookup and reviewed cache/query fixes. Local account configuration, signing keys, build caches and installed app data are excluded.

Alternatively extract the build-155 `Mira-ios-source.zip` from release v0.5.10 (folder `Mira`), then apply `Mira-ios-changes-from-155.patch`. The patch was applied and its modified files compared with this source snapshot.

The current version is 0.5.24 / 168. Older entries in MIRA_BUILD.md describe development history; this release’s validation and the public publishing guide describe the current delivery. Preserve production bundle ID `com.nuvio.media`, existing local configuration and Sideloadly signing identity.

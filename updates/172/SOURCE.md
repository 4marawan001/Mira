# Mira Fire TV 172 source

Use `Mira-FireTV-source-172.zip` for the complete Fire TV source, including the existing Media3 runtime AARs. It excludes installed account data, private signing keys, local configuration and build caches.

Alternatively restore the Fire TV source archive from build 155, then apply `Mira-FireTV-changes-from-155.patch`. The patch was applied to the base and all modified source files compared. The full archive includes the existing Android runtime AARs.

Fire TV 172 is 0.5.28. iPhone and Mac retain their independent release versions. See VALIDATION.md for checks and limitations.
